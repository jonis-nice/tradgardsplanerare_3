TRÄDGÅRDSPLANERARE 3.0 – ETAPP 2

Filer: index.html, styles.css, catalog.js, app.js.

Publicering: ladda upp samtliga fyra filer i repositoryts rot och aktivera GitHub Pages.
Öppna index.html lokalt eller via publicerad GitHub Pages-adress.

Växtbiblioteket innehåller 150 poster för vanliga trädgårdsväxter i Sverige.
Varje post har svenskt namn, vetenskapligt namn, kategori, ungefärlig höjd,
planeringsdiameter, rekommenderat planteringsavstånd, ljusläge och blomningsperiod.
Värdena är generella planeringsvärden och kan variera med sort, växtplats,
klimat, beskärning och odlingsförhållanden. Kontrollera alltid slutliga mått
för aktuell sort och ståndort innan en verklig planteringsplan fastställs.

Användning: välj växt i biblioteket, klicka Placera vald växt och klicka sedan
på ritningen. Växtsymbolerna har kategoribaserad grundfärg och påverkas inte
av formens färginställningar.

Etapp 2 är en vidareutveckling av version 3.0 etapp 1. Behåll en säkerhetskopia
av tidigare fungerande version.
